    Sign in with your email and roll number

    Use the address and roll number your teacher put on the class list. Capitals, spaces and hyphens don't matter. Both stay on this device; nothing is sent anywhere.

    Not on the list? Write to dr.fmt.hsc@gmail.com from the address you want added, with your roll number.

    Add students to the class list

    Nothing typed here changes who can read the notes. This tab only works out the sealed lines. The class list changes when you paste them into notes/index.html and commit the file, which only you can do.

    1. Type your class word. It is the key the notes are locked with, and only you need it.
    2. Load a spreadsheet, or paste one student to a line as email then roll number. Either way, the box must hold the whole class every time, not only the new students.
    3. Press Build the list, copy what appears, and paste it into notes/index.html in place of the old const ROLL = [ … ]; line.
    4. Commit the file. The new students can sign in a minute later.

    Two columns: the email address and the roll number, in either order. A heading row is ignored. Old .xls files and Numbers files aren't read; save them as CSV first.

    Neither the addresses nor the roll numbers are written into the page in readable form. Each line holds a one-way fingerprint of the pair, and the class key sealed with the pair, so a reader of the source sees none of the three. A student needs both halves, which is why a guessed email alone gets nobody in. Removing a line stops a new sign-in from that student; anyone already signed in keeps their copy of the key until you change the class word and rebuild the topics.
